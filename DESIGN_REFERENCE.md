# OmniComm 360° — Design Reference

The attached professional dashboard mockup is the single visual reference for this build.

## Rule
Preserve the original OmniComm 360° idea and functionality while adopting the mockup's visual language and information architecture: dark professional console, left navigation, global search, KPI cards, recent activity, quick actions, notifications, environments/system health, and a dense but readable enterprise dashboard.

Do not replace OmniComm 360° with the mockup's product concept or branding. The mockup is a UI/UX reference only.
